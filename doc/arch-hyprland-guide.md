# Arch Linux + Hyprland installation guide — moved

The guide lives in the **archinstall** repo:
**[zrrbite/archinstall: doc/arch-hyprland-guide.md](https://github.com/zrrbite/archinstall/blob/main/doc/arch-hyprland-guide.md)**

That copy is maintained: it covers Hyprland's `hyprland.lua` config format,
current packages, Secure Boot, Wi-Fi, NVIDIA and more. The version that used
to be here came from this repo's old `main` branch (December 2025) and had
fallen behind. It's still in git history (`git show 248f0c1:doc/arch-hyprland-guide.md`).

Use the guide to install Arch itself. Then apply these dotfiles with
`install_arch.sh`, following Path A in [applying-the-setup.md](applying-the-setup.md).
